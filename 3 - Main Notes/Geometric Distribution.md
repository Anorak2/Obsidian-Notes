# Geometric Distribution
What geometric does is count the number of events until we see a 1, this is also actually just a special case of the Pascal Distribution where k = 1

**PMF**
$P(K) = p(1-p)^{k-1}$

where $k = 1, 2, 3, ...$


Given $0 < p < 1$:
$$\sigma_x = \frac{\sqrt{1-p}}{p}$$
$$E[x]= \frac{1}{p}$$
$$E[x^2]= \frac{2-p}{p^2}$$
$$\sigma_x=\frac{\sqrt{1-p}}{p}$$
and 
$$C_x = \sqrt{1-p}$$
