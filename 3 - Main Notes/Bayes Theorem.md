# Bayes Theorem
There are many times when we want to assess the probability that a particular event occurs on the basis of partial evidence:
- The probability that a person has a disease given that this person tests positive for a diagnostic test for the disease.
- The probability that an incoming e-mail message is spam using the occurrence of words in the message.
The result that we can use to answer questions such as these is called Bayes’ theorem which dates back to the eighteenth century.
