# Terraform Basics
Infrastructure as Code (IaC) tools allow you to manage infrastructure with configuration files rather than through a graphical user interface. By doing this we can build, change, and manage infrastructure in an auditable, consistent, and repeatable way by defining resource configurations that can be tracked through versions, be reused easily, and shared.

**Plugins:**
Terraform plugins called providers let Terraform interact with cloud platforms and other services through API's, allowing integration into many services such as Azure, AWS, GCP, Kubernetes, and more.

**Core Work Loop**
1. find out what infrastructure is needed
2. Write the configuration files
3. Install the required Terraform providers
4. Preview the changes
5. Apply the changes
