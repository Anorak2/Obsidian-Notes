# Social Network Search and Recommendations
## Search
While the goals of users on social networks are different from the rest of the web the user behavior is similar to web search. This means a small number of queries per session and users tend to browse just the first few results.

The key outline of important topics vs web search is:
Crawling
- Refreshing frequency
- Specialized parsing, since just HTML isn't good enough
Ranking
- Importance -> popularity
- Freshness
- Content similarity for short text segments
- Trustworthiness?

## Graph Search
This was formerly a part of Facebook's search feature with the core idea that I trust my friends, and probably my friend's friends more than the average user and that should be reflected in ranking. But we can take this further, semantic search is examples like Restaurants in Overland Park, People who work at KU, Photos of Edwards campus.  This leads us to Semantic graph search with results like: Restaurants in Overland Park liked by my friends,  my friends who work at KU. This is feasible since Facebook has the friendship graph and structured attributes as part of their network.

TikTok search: searching for people, posts, sounds, hashtags, and more
- Discover/Search flow emphasizes trending videos, creators, and hashtags
- Nearby Feed for local discovery
- Creator Search Insights: what users are searching for

Instagram search: finding photos/videos, hashtags, accounts, audio, tags, and places
- Explore is recommendation-driven

Reddit search: includes search within communities, comment search, Boolean operators, manual filters, etc.
- A beta AI-powered “Answers” feature... I don't like this one
