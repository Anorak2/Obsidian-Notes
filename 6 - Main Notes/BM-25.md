# BM-25
BM25 is a classic probabilistic ranking function for information retrieval. It has the philosophy of reward multiple occurrences of a term in the document but not linearly forever (TF saturation), rewarding rare terms, and normalizing on document length.

For this metric to be useful we want $𝑃(𝑅𝑒𝑙𝑒𝑣𝑎𝑛𝑡|𝑞, 𝑑_1) > 𝑃(𝑅𝑒𝑙𝑒𝑣𝑎𝑛𝑡| 𝑞, 𝑑_2)$ to imply that $𝑑_1$ is more likely relevant.

**Rewarding Rare Terms:**
$$idf_t=\ln\frac{N-df_t+0.5}{df_t+0.5}$$
We add 0.5 on the bottom as a stability trick to avoid division by 0 and extreme weights for rare terms, it also makes IDF less "jumpy" for rare terms. Something else to note is that in this model extremely common words contribute negatively to the search. We can fix this by either removing stop words, raising all negative scores to 0, or by taking $idf=\log (1\space +\space ...)$ instead.

**Saturation:**
i.e. not rewarding terms linearly forever
$$\frac{ tf_{t,d}(k_1 + 1) } { tf_{t,d}+k_1 }$$
$k_1$ controls how quickly TF saturates,with a typical value of \[1.2 - 2.0\] with a higher value penalizing longer documents more. When TF is small increases in TF quickly increase the score, but when TF is large it approaches $K_1$.

**Normalize on document length:**
Long documents naturally contain more terms, so they can match queries more often just by being long. BM25 adds a length normalization factor using document length |d| and average document length `avgdl`.

$$K_d=k_1(1-b+b\cdot \frac{|d|}{avgdl})$$
where $b \in [0, 1]$ controls the strength of length normalization, b=0 means no length normalization and b=1 means full normalization by length ratio.

**Combined Metrics:**
$$BM25=\sum_{t \in q}idf(t)\cdot \frac{tf_{t,d}(k_1 +1)}{tf_{t,d}+K_d}$$
Thus
$$BM25 = \sum_{t \in q} idf(t)\cdot \frac{tf_{t,d}(k_1 +1)}{tf_{td}+k_1(1-b+b\cdot\frac{|d|}{avgdl})}$$
