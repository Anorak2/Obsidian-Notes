# Deep Belief Network
Deep learning is a sub-field of machine learning with the idea that as you progress through the layers they become more and more meaningful. The number of layers is called the depth, and there can be tens to hundreds of them. Also, as you might expect machine learning with only one or two layers is called shallow learning.

In deep learning we are almost always using Neural Networks with multiple hidden layers.
