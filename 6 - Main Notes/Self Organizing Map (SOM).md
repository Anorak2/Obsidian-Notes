# Self Organizing Map (SOM)
The main disadvantage with some of the other Unsupervised ML clustering models (k-Means and GMM) is that they are probabilistic. They have the same drawback that probabilistic Supervised ML models (Naïve Bayes, Regression, LDA, QDA) do, which is that the real world does not always perform in a probabilistic way.

A Self-Organizing Map (SOM) is a type of neural network that is trained using unsupervised learning to group unlabeled input samples into classes. The most common form of a SOM is an n x n grid where each square (hex in the diagram) in the grid may hold none, one, or more samples. Samples in a square are similar to each other (so you can think of the squares as clusters). But also samples in adjacent squares are more similar to samples in squares that aren’t adjacent.
