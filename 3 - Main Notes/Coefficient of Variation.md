# Coefficient of Variation
The coefficient of variation is a more direct indication of the variability than variance, that also isn't dependent on the value of the mean. This coefficient is defined as:
$$C_x = \frac{\sigma_x}{E[x]}$$
Note that if $C_x$ is ever zero it means that all of the values are identical.
